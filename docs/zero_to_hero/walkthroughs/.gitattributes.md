`.gitattributes` gives Git **per-file instructions**. We use it for one important job: making line endings identical on every computer (§4.1), and making sure binary files are never "corrected" as if they were text.

Each line is a file pattern followed by attributes.

@@ 1
A comment — lines starting with `#` are notes for humans.

@@ 2
`* text=auto eol=lf`:

- `*` — every file;
- `text=auto` — let Git decide whether a file is text. It looks for bytes that only appear in binary files;
- `eol=lf` — for text files, store and check out lines ending with a single line feed, even on Windows.

Without this line, a Windows checkout could turn every line into CRLF. Shell scripts copied into Linux containers would then break, and diffs would show every line as changed.

@@ 4
A comment introducing the binary list.

@@ 5-11
File types that must **never** be treated as text, each marked `binary`. This turns off line-ending conversion — which would corrupt them — and stops Git from trying to show a line-by-line diff of their bytes.

| Pattern | What it is |
| :-- | :-- |
| `*.png`, `*.jpg`, `*.jpeg`, `*.webp` | images (logos, screenshots, test pictures) |
| `*.ico` | the website's tab icon |
| `*.woff2` | web fonts |
| `*.onnx` | AI model files (normally never committed, see `.gitignore` — but if one ever is, it must stay intact) |
