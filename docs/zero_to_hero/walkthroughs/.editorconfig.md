**EditorConfig** is a standard settings file that most code editors read automatically: VS Code, all JetBrains editors, Vim, Visual Studio and more. It tells every contributor's editor the same basic rules — encoding, line endings, indentation — so files don't get silently changed just because two people use different editors.

The format is simple:

- `[pattern]` lines choose which files the settings below them apply to;
- `key = value` lines set a rule.

@@ 1
`root = true` — "this is the top-level settings file; stop looking in parent folders for more". Without it, a stray `.editorconfig` somewhere above the project could change our rules.

@@ 3
`[*]` — the rules below apply to **every** file (`*` matches any name).

@@ 4
`charset = utf-8` — save files as UTF-8, the encoding that can hold every character in every language (§0.2).

@@ 5
`end_of_line = lf` — end lines with a single *line feed*, the Linux/macOS convention. This matches what `.gitattributes` stores, so editors on Windows don't fight Git (§4.1).

@@ 6
`insert_final_newline = true` — always end a file with a newline. By the classic definition, a text line *ends* with a newline, and many tools (and Git's diffs, which otherwise show "No newline at end of file") expect it.

@@ 7
`trim_trailing_whitespace = true` — remove invisible spaces at the ends of lines. They do nothing, but they show up as noisy changes in code reviews.

@@ 8-9
`indent_style = space` and `indent_size = 2` — indent with spaces, two at a time, by default. Two spaces is the usual convention for JavaScript, TypeScript, JSON and YAML.

@@ 11-12
`[*.py]` with `indent_size = 4` — Python files use **four** spaces per level, the convention set by Python's official style guide (PEP 8). In Python, indentation is part of the meaning (§X.8), so consistency matters even more.

@@ 14-15
`[*.md]` with `trim_trailing_whitespace = false` — in Markdown, **two spaces at the end of a line** mean "line break here". Trimming them would silently change how text is displayed, so Markdown files are exempt.
