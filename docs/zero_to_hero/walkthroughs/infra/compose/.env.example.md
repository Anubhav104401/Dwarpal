An **example settings file**. Docker Compose automatically reads a file named `.env` in the same folder as the Compose file, and uses its values to fill the `${…}` placeholders in `compose.yaml`.

The real `.env` is never committed (see `.gitignore`), because in a real deployment it holds secrets. This *example* is committed so everyone can see which settings exist. To use it, copy it to `.env` and change the values.
