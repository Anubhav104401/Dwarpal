*[API]: Application Programming Interface — a menu of requests one program offers to other programs
*[APIs]: Application Programming Interfaces — menus of requests programs offer to other programs
*[HTTP]: HyperText Transfer Protocol — the rules browsers and servers use to talk
*[HTTPS]: HTTP inside an encrypted, tamper-proof envelope (TLS)
*[TLS]: Transport Layer Security — the technology behind the browser padlock
*[JSON]: JavaScript Object Notation — a plain-text format for structured data
*[HTML]: HyperText Markup Language — describes what is on a web page
*[CSS]: Cascading Style Sheets — describes how a web page looks
*[SQL]: Structured Query Language — the language for asking a database questions
*[CPU]: Central Processing Unit — the chip that follows a program's instructions
*[GPU]: Graphics Processing Unit — a chip that does thousands of calculations at once; ideal for AI
*[RAM]: Random-Access Memory — fast, temporary working memory that forgets when power is off
*[DNS]: Domain Name System — the internet's phone book, turning names into IP addresses
*[VM]: Virtual Machine — a slice of a big computer that behaves like a private computer
*[VPS]: Virtual Private Server — a rented virtual machine
*[MAE]: Mean Absolute Error — the average size of a model's mistakes, ignoring their direction
*[PAD]: Presentation Attack Detection — spotting photos, screens and masks held up to a camera
*[NIST]: National Institute of Standards and Technology — the US standards body that tests age-estimation systems
*[DPDP]: Digital Personal Data Protection — India's 2023 data-protection law
*[GDPR]: General Data Protection Regulation — the EU's data-protection law
*[DPIA]: Data Protection Impact Assessment — a formal study of privacy risks, done before processing personal data
*[WCAG]: Web Content Accessibility Guidelines — the international rules for accessible websites
*[SDK]: Software Development Kit — a ready-made package that makes a service easy to use from code
*[JWKS]: JSON Web Key Set — a published list of public keys that anyone can use to check signatures
*[ONNX]: Open Neural Network Exchange — a standard file format for AI models
*[TOML]: Tom's Obvious Minimal Language — a simple, readable format for settings files
*[URL]: Uniform Resource Locator — a web address
*[OCR]: Optical Character Recognition — reading printed text from a picture
*[MRZ]: Machine-Readable Zone — the lines of code-like text at the bottom of a passport
*[UIDAI]: Unique Identification Authority of India — the agency that issues Aadhaar
*[AGPL]: Affero General Public License — a copyleft licence that applies even to software offered over a network
*[SHA-256]: Secure Hash Algorithm, 256-bit — turns any data into a fixed-size fingerprint
