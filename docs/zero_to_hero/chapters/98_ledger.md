# Coverage ledger

This table is **generated by the program that builds the book**, not typed by hand. Every time the book is built, the builder:

1. walks through every folder of the project and lists every code and configuration file (ignoring folders full of downloaded libraries or generated files);
2. for each file, finds its walkthrough and counts how many **non-blank** lines have an explanation;
3. compares the file's current fingerprint with the fingerprint recorded when it was explained.

A file is **complete** only when every non-blank line is explained **and** the code has not changed since. Blank lines are not counted, because there is nothing on them to explain.

Some files are deliberately left out:

- the generated book itself (`zero_to_hero.html`);
- **lockfiles** (`uv.lock`, `pnpm-lock.yaml`), which are long machine-written lists of exact library versions. We explain what lockfiles *are* (§0.17) rather than explaining thousands of machine-written lines.
